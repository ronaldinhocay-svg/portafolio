# Portafolio para GitHub Pages

Esta carpeta contiene una copia independiente del portafolio, lista para publicarse como sitio estático.

## Archivos necesarios

- `index.html`: la página del portafolio.
- `ezgif-6fe42adae05a6eb4-png-split-transparent/`: los 238 fotogramas transparentes de la animación.

No subas únicamente `index.html`: la animación necesita la carpeta de fotogramas y su nombre debe mantenerse igual.

## Publicación

1. Crea un repositorio en GitHub Desktop usando esta carpeta como ubicación local.
2. Publica el repositorio en tu cuenta de GitHub.
3. En el repositorio, ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda.

Como la animación contiene muchos fotogramas, GitHub Desktop es más práctico que subir los archivos uno por uno desde el navegador.
